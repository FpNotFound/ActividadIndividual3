# Actividad Individual 3

## Códigos Unidad Formativa 3

Este repositorio contiene la implementación de los ejercicios correspondientes a la Actividad Individual 3 de la Unidad Formativa 3.

## Contenido

### Dynarray

- **Dynarray1:** Dynarray genérico para almacenar enteros, realizar inserciones, eliminaciones y búsquedas.
- **Dynarray2:** Dynarray genérico para almacenar cadenas, ordenarlas alfabéticamente y realizar búsquedas.
- **Dynarray4:** Dynarray genérico capaz de almacenar objetos de una clase personalizada.

### Vector

- **Vector1:** Vector genérico para analizar las ventas diarias de productos durante un mes.
- **Vector2:** Vector genérico para gestionar precios y cantidades de productos de un supermercado.
- **Vector3:** Vector genérico para almacenar y analizar las calificaciones de estudiantes por asignatura.
